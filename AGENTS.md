# Replay agent guidance

- Replay is a four-hour hackathon MVP. Optimize for proving the core idea quickly.
- Browser Use will handle autonomous browsing in a later milestone.
- OpenRouter will handle capability reasoning in a later milestone.
- Do not add a database, authentication, or Temporal unless explicitly requested.
- Follow the smallest-change principle: add only what the current milestone needs and avoid speculative abstractions.
- Every milestone must pass typecheck, lint, and build before proceeding.
